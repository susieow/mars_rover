## 3. 第一组：只改变前、中、后轮组速度

本方案将用户所说的“三个轮”解释为前、中、后三个轮组，每组包含左右两轮。单组加速时，该组左右轮的基准目标同时变化，另两组继续保持3 rad/s。沿用原航向修正和转向控制，记录修正前基准目标、修正后六轮目标及实际六轮速度。

每条从22秒父检查点恢复后，选中的轮组用3秒线性地从3增至6 rad/s，即目标增速1 rad/s²；达到6后保持。绝对时间22～25秒加速，随后保持，最长运行到52秒。没有选中的轮组始终保持3。每条最多续跑30秒，因既有终止条件或六轮平台支撑提前结束时记录实际时长。不同轮组的加速在候选相对时间0同时开始。

| 编号 | 渐增速的轮组 | 3秒后前/中/后轮组基准目标，rad/s |
|---|---|---|
| W-F | 前 | 6 / 3 / 3 |
| W-M | 中 | 3 / 6 / 3 |
| W-R | 后 | 3 / 3 / 6 |
| W-FM | 前、中 | 6 / 6 / 3 |
| W-FR | 前、后 | 6 / 3 / 6 |
| W-MR | 中、后 | 3 / 6 / 6 |

这7条的左右摇臂目标仍为0°，采用原有限力矩反馈，不锁死实际摇臂角度。3秒是本轮固定的加速设计，尚未验证为最佳；不同时扫描多个加速时间。

这里的6 rad/s是轮组基准目标。原航向修正仍可让左右最终轮目标在其附近变化，不能在前端把两者混为一谈；最终目标继续受原URDF轮速范围约束。

## 4. 第二组：相同7种轮组加速，加上左右摇臂摆动

左右摇臂指车身两侧绕各自关节轴转动的主动关节，不是左右打方向。沿用原驱动力矩与反馈限幅，只增加随时间变化的摇臂角度目标。实施前静态核对两关节正负号与轮心变化，视频和记录明确显示正负方向。

首轮固定幅度为±10°，目标移动速度10°/s。该幅度是探索参数，不是新的安全限值。保持原摇臂期望速度限幅±0.7 rad/s、力矩±100 N·m、URDF速度1.57 rad/s及现有关节角度边界；实际超速仍记录。

定义P为8秒的一次目标摆动：

| 相对周期时间 | 目标角度 |
|---|---|
| 0～1秒 | 0°逐渐到+10° |
| 1～2秒 | 保持+10° |
| 2～4秒 | +10°逐渐到−10° |
| 4～5秒 | 保持−10° |
| 5～6秒 | −10°逐渐回到0° |
| 6～8秒 | 保持0° |

负P表示整个序列符号反转。从候选相对时间0开始，与轮速渐增同时执行。重复3个周期共24秒，最后6秒保持0°目标，观察摆动结束后能否保住已经取得的进展。原状态与实际速度连续，不瞬移摇臂或重置车轮。

| 编号 | 左摇臂 | 右摇臂 | 比较目的 |
|---|---|---|---|
| R-S+ | P | P | 同向摆动，先正向 |
| R-S− | −P | −P | 同向摆动，先负向 |
| R-D+ | P | −P | 左右反向摆动，左侧先正向 |
| R-D− | −P | P | 左右反向摆动，右侧先正向 |

7种轮组加速分别配4种摇臂动作，共28条。首轮不再叠加幅度、频率、单侧独动或不同启动延迟，避免失去可比较性。若全部失败，只能说这组动作范围内未成功，不能推广为所有摇臂策略均无效。
